# DSA Using C

A beginner-friendly collection of Data Structures and Algorithms implemented in C.

## Searching
- Linear Search
- Binary Search

## Sorting
- Bubble Sort
- Insertion Sort
- Selection Sort

## Compile and Run

Install GCC and open a terminal in the folder containing the program.

Example:
gcc BinarySearch.c -o BinarySearch

Run in PowerShell:
.\BinarySearch.exe
